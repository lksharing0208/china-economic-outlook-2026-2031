# AI 用电需求与能源科技 A 股研究清单（2026—2031）

> **定位：产业研究与跟踪框架，不是买入名单。** 本文区分发电运营、电网设备、储能与数据中心基础设施，以及早期技术方向。公司入选只表示值得研究，不代表估值合理、确定受益或未来业绩/股价翻倍。

## 一、核心判断

AI 算力增长可能推动数据中心用电、供配电、备用电源和散热需求上升；与此同时，电网扩容、新能源并网、储能调节和能源数字化也可能受益。投资逻辑应沿着“**需求增长 → 资本开支 → 订单 → 收入 → 扣非利润 → 现金流 → 估值**”逐层验证。

必须区分四件事：

1. **用电量增长不等于电价上涨。** 电价受市场交易、供需、政策和区域条件影响。
2. **发电量增长不等于利润同比增长。** 煤价、来水、利用小时、融资成本和资本开支都影响利润。
3. **行业订单增长不等于每家公司受益。** 份额、竞争、交付和客户认证决定实际兑现。
4. **营收或利润翻倍不等于股价翻倍。** 股价还取决于估值起点、资本结构、市场预期与风险偏好。

## 二、需求背景与数据使用原则

本专题早期版本引用了公开资料中的数据估计：2025 年中国算力中心用电约 1700 亿千瓦时，近三年平均增速约 39.5%；并引用了 2030 年用电规模可能显著上升的行业预测。

这些数字在使用前应回到原始发布机构核实定义、统计边界、发布日期和预测假设。**算力中心、数据中心、IDC 以及全社会用电的口径可能不同；预测值不可当作已实现事实。** 本文不把未经逐项复核的远期估计作为个股盈利预测依据。

研究中优先追踪：
- 全社会用电量与数据中心用电的实际增速；
- 数据中心建设、上架率、PUE、供电容量和电网接入周期；
- 电网年度投资、招标和设备交付；
- 储能项目实际收益率、利用小时、容量/辅助服务机制；
- 上市公司最新公告、定期报告和订单兑现情况。

### 发电运营商的筛选原则

- 核电、水电更适合从长期资产和现金流角度研究，但新项目回报仍取决于建设成本、投产节奏和电价。
- 火电在电力系统中可能承担调峰和容量保障功能，但盈利高度依赖煤价、电价与容量补偿机制。
- 风光运营商需重点分析利用小时、消纳、电价和融资成本，不能只看装机增长。
- 独立售电公司与拥有发电资产的运营商商业模式不同，需单独核实价差、客户结构及风险，不宜简单归为“卖电受益”。

## 六、先进核能与核聚变：单独列为高不确定性观察池

核聚变相关材料、超导、磁体、电源、真空系统和特种装备可能存在长期产业机会，但商业化时间、产业链分工和上市公司收入贡献存在较大不确定性。

筛选前至少核实：
1. 公司是否有明确、可核验的项目或供货关系；
2. 相关业务是否形成合同、交付和实际收入；
3. 该业务占公司收入和利润的比例；
4. 是否依赖科研经费、样机订单或远期规划；
5. 当前估值是否已经计入高度乐观的商业化假设。

**不因公司参与科研、被媒体归入概念板块或拥有少量相关业务，就认定其为核聚变核心标的。**

## 七、如何判断“营收/利润翻倍潜力”

“翻倍”应先明确指标和时间：营收翻倍、扣非净利润翻倍与股价翻倍是不同目标。建议逐项通过以下检查：

| 维度 | 正向证据 | 风险信号 |
|---|---|---|
| 需求 | 实际项目、资本开支和付费需求增长 | 只有规划，没有落地 |
| 订单 | 新签订单增长，订单能转化为收入 | 低价中标、交付延期、回款变差 |
| 收入 | 核心业务持续增长，收入结构改善 | 依靠并购或一次性项目 |
| 利润 | 扣非利润增长，毛利率和净利率稳定 | 营收增长而扣非利润下降 |
| 现金流 | 经营现金流与利润相匹配 | 应收账款、存货快速上升 |
| 资本回报 | 新增资本开支带来合理回报 | 高负债扩张、ROIC下降 |
| 估值 | 估值与可持续增长相匹配 | 预期过高，业绩稍有不及即大幅回撤 |

## 八、研究优先级与持续跟踪

可先建立三个观察池，不直接合并为一份买入排名：

- **长期发电资产：** 中国核电、中国广核、长江电力、华能水电、国投电力；重点看现金流、项目兑现、估值与分红。
- **电网与高端电气设备：** 国电南瑞、思源电气、许继电气、平高电气、中国西电、金盘科技、特变电工；重点看订单、利润率与回款。
- **数据中心供电、储能和热管理：** 宁德时代、亿纬锂能、阳光电源、科华数据、中恒电气、科士达、海博思创、英维克；重点看相关业务的实际收入、客户订单与现金流。

更新公司名单时，优先使用交易所公告、上市公司定期报告、国家能源局和国家电网/南方电网公开资料。对每条数据记录统计期、发布日期、口径和来源链接。未核实的数据应标记“待核实”，不以精确数字制造确定性。
