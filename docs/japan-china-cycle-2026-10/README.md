# 日本战后周期 × 中国经济周期对照（2026-10 专题）

> 数据截至 2026-10-12（个别市场数据为 10 月 8 日前后）。本专题是情景分析，不是预测或投资建议；所有数字以官方发布和公司公告为准。

## 一句话结论

- **位置：** 以日本为参照，中国的发展阶段约相当于日本 1970s 末至 1980s（增速换挡），金融周期约相当于日本 1995–96（泡沫破裂后第 5 年的政策托底窗口），老龄化程度约相当于日本 1997 前后，但人均收入水平远低于日本当时。
- **去油价后：** 内需读数更接近日本 1994–95。表面的“通缩结束”主要由油价推动；出口与高端制造是真实支撑，整体呈 K 型结构。
- **分岔点：** 2027–2028 年，对应日本 1997 年的“财政退出 + 外部冲击”。
- **个人与投资（不含房产投资）：** 先保现金流和负债安全，再分批配置。人民币债券做稳定器，A/H 股以“宽基 + 红利”为底仓、科技成长做卫星，美元短久期资产做分散，黄金小比例。
